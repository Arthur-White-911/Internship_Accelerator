# 实习加速器 · 网申助手 浏览器扩展

> 一款专为高校学生设计的网申辅助 Chrome 扩展，与「实习加速器」平台深度集成，帮助你高效完成实习申请。

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| **职位识别** | 自动识别招聘网站（智联、BOSS直聘、LinkedIn 等）当前页面的职位信息 |
| **一键填表** | 根据你保存的个人信息，智能匹配并自动填写网申表单字段 |
| **进度追踪** | 收藏职位并追踪申请状态（已收藏 / 已投递 / 面试中 / 已拿 Offer / 已拒绝） |
| **我的信息** | 安全存储个人资料（姓名、学校、专业等），用于自动填表 |
| **悬浮按钮** | 在任意网页右下角显示悬浮入口，一键呼出助手 |

## 支持的招聘平台

- 智联招聘 (zhaopin.com)
- 前程无忧 (51job.com)
- 猎聘 (liepin.com)
- BOSS 直聘 (boss.zhipin.com)
- 拉勾网 (lagou.com)
- LinkedIn (linkedin.com)
- Greenhouse、Lever、Workday 等国际平台
- 以及其他任意招聘网站（通用识别模式）

## 安装方法

### 开发者模式安装（推荐）

1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/`
2. 开启右上角的 **「开发者模式」** 开关
3. 点击 **「加载已解压的扩展程序」**
4. 选择本项目中的 `extension/` 目录
5. 扩展安装成功，工具栏将出现闪电图标

### 使用步骤

1. **填写个人信息**：点击扩展图标 → 「我的信息」标签 → 填写并保存
2. **识别职位**：打开任意招聘网站的职位详情页 → 点击「识别职位信息」
3. **收藏职位**：识别后点击「收藏职位」，在「进度追踪」中管理
4. **自动填表**：打开网申表单页面 → 点击「一键填写表单」

## 目录结构

```
extension/
├── manifest.json          # 扩展配置文件（Manifest V3）
├── popup.html             # 弹窗页面
├── icons/
│   ├── icon16.png         # 16×16 图标
│   ├── icon48.png         # 48×48 图标
│   └── icon128.png        # 128×128 图标
└── src/
    ├── background.js      # Service Worker（数据存储与消息路由）
    ├── content.js         # 内容脚本（页面识别与表单填写）
    ├── content.css        # 悬浮按钮与提示样式
    ├── popup.js           # 弹窗交互逻辑
    └── popup.css          # 弹窗样式
```

## 隐私说明

- 所有个人信息**仅存储在本地浏览器**（`chrome.storage.local`），不上传至任何服务器
- 扩展不收集任何用户行为数据
- 仅在用户主动操作时读取页面内容

## 技术规格

- **Manifest 版本**：V3（最新标准）
- **权限**：`storage`、`activeTab`、`scripting`、`tabs`
- **兼容性**：Chrome 88+、Edge 88+（基于 Chromium 的浏览器）
